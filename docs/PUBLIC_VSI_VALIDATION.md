# Public VSI v1 sample checks

The Base route is ready for a full evaluation. Both QUASAR routes remain blocked. No new full-table answers or scores are included.

The twelve fixed questions span eight task groups, three video sources and four station expressions. Their original videos were decoded, and Base processor checks passed on all twelve questions and their 32-frame inputs. All 5,130 Base questions keep their original text and options; 671 short option sets are not expanded.

Six semantic samples were run through the frozen reference estimator. Two produced estimates that passed independent review of object identity and heading; four did not, because the named object or its surface could not be identified reliably in the frames. The protocol does not replace failed samples, so both QUASAR routes stay blocked. The sample preparation command in [PUBLIC_VSI.md](PUBLIC_VSI.md) writes the per-sample records.

CPU checks cover answer isolation, original options, expression parsing, rigid rotations, missing geometry/patches, wrong coordinate systems and ordered resume. The conversion outputs for 5,130 VSI and 6,042 VSTI records are equivalent as structured data.
