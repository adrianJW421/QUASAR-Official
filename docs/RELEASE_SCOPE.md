# Release material and access

This release contains the four-summary-token implementation, [input construction](INPUT_EXAMPLES.md), [added-weight loading](../checkpoints/README.md) and the [numerical-reference comparison](NUMERIC_POSE.md). The table lists what is included and what must be obtained elsewhere.

| Material | In this release | Access or remaining action |
| --- | --- | --- |
| Training QA | Downloaded separately; not included in the repository | `TOBEADD`; save the 426,916 ordered rows as `data/annotations/sft_426916_qa.jsonl`; original text, answers, source licenses and repeated IDs are kept ([data guide](../data/README.md)) |
| Saved validation QA | 17,651 ordered rows | `data/annotations/validation_17651_qa.jsonl`; labels are kept separate from inference inputs |
| Historical Base VSI scoring inputs | 5,130 rows, original option version | `data/annotations/vsi_m01_5130_scoring.jsonl`; the historical Base run (M01) used raw video, unlike the trained models |
| Member, order and target-availability lists | Training, validation, both 8,192-group GRPO runs, evaluation subsets and donor maps | `data/manifests/` and `experiments/interventions/`; both GRPO runs link to exact source rows |
| Original answers and score summaries | Eleven of the paper's experiment groups; 33 answer conditions | `experiments/`; the [experiment index](EXPERIMENT_INDEX.md) lists which groups are included |
| Independent main-table run | Seven completed cells | `results/reproduction_20261007/`; see [reproduction results](REPRODUCTION_RESULTS.md) |
| Numerical-reference control | Counts, scores, subsets and intervals | `results/numeric_pose_20261008/`; 22,344 answers on the historical inputs; not a main-table result |
| Station/heading construction | Coordinate conversion and a synthetic teaching example | Known object/observer locations and a documented alignment are supplied by the caller |
| Qualitative cases | Source inventory | Original model-view material and presentation images are not included |
| Qwen backbone and project weights | No weights in the source | Official Qwen revision plus W01, W02, W05 and W06; see [checkpoint guide](../checkpoints/README.md) |
| RGB/video, scans, depth and camera poses | No raw media | Obtain from the original providers under their terms; frame and source mappings are in [ACQUISITION.md](../data/ACQUISITION.md) |
| Reference definitions and original object/training annotation | Availability and member records only | Answering inputs are rebuilt from original media/depth with sourced references; historical training-target generation and some semantic conversions are incomplete |
| Computed geometry and feature caches | Not included | Generated by users under `runs/` |
| VSTI evaluation questions and answers | Member and donor IDs only | The dataset card states no data license, so they are not redistributed; download them from the provider and follow its terms |
| CUT3R | Build helper, license and installation instructions | Obtain CUT3R code and weights; build `curope` with `scripts/build_cut3r_extension.py` |

The [download guide](../data/DOWNLOAD_GUIDE.md) lists official sources for training and evaluation QA, videos, scans, depth/cameras and external benchmarks. [Generation](../data/GENERATION.md) separates the runnable answering routes from the historical generation steps that are missing. Original project code uses Apache-2.0 and project-added weights use CC-BY-NC-4.0; included QA keeps each source's license ([license scope](../LICENSE_SCOPE.md)).

## Known limitations

- **Public VSI:** Base input preparation passed on twelve real videos; a full 5,130-question public Base run is not included. Both QUASAR cells are blocked because the 1,162 semantic viewpoints cannot yet be estimated reliably from public inputs ([sample checks](PUBLIC_VSI_VALIDATION.md)).
- **Historical reference inputs:** The numerical-reference control uses the retained historical inputs. For the 1,162 semantic VSI questions these are scene-centre placeholders, and VSTI uses the repaired `provided_full` references. The control therefore does not show that the selected references are semantically correct. In VSTI item 590 the question refers to the start orientation, but the retained parser selects the end frame; this behavior is kept and reported. These statements apply to the retained historical inputs only.
- **Independent main-table differences:** VSTI QUASAR SFT changes from 65.11149951886060 to 65.13935064154531, and SFT+GRPO from 66.18587065462481 to 66.03231694389243. Questions, options, pixels, geometry and references match; the historical feature caches and execution environment could not be compared. Both values are reported and the cause is unknown.
- **Historical reproduction and training:** Some historical training and conversion details were not recorded, and full training and all ten main-table cells have not been reproduced; see [REPRODUCIBILITY.md](REPRODUCIBILITY.md#historical-details-not-recorded).
- **Availability:** Public download links for W01, W02, W05 and W06 are not yet available. VSTI questions, answers and media come from the official provider; third-party terms apply.
